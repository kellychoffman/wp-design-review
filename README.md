# WP Design Review

*Working title.* Share the look, not the editor.

A WordPress review-link product: a signed, expiring URL that shows a published page (or the whole site) with pending redesign styles applied, so a client can review the look without ever logging in or seeing the Site Editor.

**Share a link. They see the real site looking like the redesign. They leave feedback. You publish when it's done.**
