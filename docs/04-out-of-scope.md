# Out of scope for v1

Deliberately not here, so the first version stays a link you can explain in a sentence.

- **Full collaborative editing.** Reviewers look and comment. They don't change things.
- **Realtime multiplayer (cursors, live co-presence).** Nobody needs to watch each other scroll.
- **Agent actors.** No AI reviewers or auto-applied feedback. Comments are written by people and acted on by people.
- **Custom CSS dumping.** A review shows a look built from the site's own styles system. It is not a place to paste arbitrary CSS.
- **A hard permissions model.** Soft approve is a signal, not a gate. No approval workflows, roles or sign-off chains.
- **Visitor accounts.** A name typed once is enough.
- **Side-by-side compare.** Toggle first. Split view is a desktop follow-up.
- **Multi-site or network-wide reviews.** One site at a time.
- **Reviewing template or layout changes** beyond what the site's styles and content already express. Layout review ships once the core path is proven.
- **Analytics on visitors.** The audit log answers "who could see what," not "how long did Dana look."
